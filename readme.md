
# Instruction
## Task
Find all pairs of Solar system planets
## Game start
Game starts automatically on page load and by clicking "New Game" button(incl. in modal after current game coplition)
## Leader Board
You can check leader Board by clicking button "Leaders"
## Local run
Open index.html in google chrome

# Инструкция
## Цель
Найдите все пары планет солнечной системы
## Начало игры
Игра стартует автоматически после загрузки страницы ил нажатия кнопки "New Game"(в.ч. в модальном окне после завершения текущей игры)
## Доска лидеров
Для просмотра лидеров  нажмите кнопку "Leaders"
## Локальный запуск
Откройте файл index.html в google chrome
